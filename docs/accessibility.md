# 可訪問性指南

本文檔提供了關於小星專注力應用程式的可訪問性功能和最佳實踐的詳細說明。

## 鍵盤導航

### 主要導航
- 使用 `Tab` 鍵在頁面元素之間移動
- 使用 `Enter` 鍵激活按鈕和連結
- 使用 `Esc` 鍵關閉彈窗或退出全螢幕模式

### 遊戲控制
- `空白鍵`：點擊目標（在反應力遊戲中）
- `P` 鍵：暫停/繼續遊戲
- `M` 鍵：切換音效
- `F` 鍵：切換全螢幕模式

## 高對比度模式

應用程式提供高對比度模式，可以通過以下方式啟用：
1. 點擊頂部導航欄中的對比度切換按鈕
2. 使用鍵盤導航到對比度切換按鈕，然後按 `Enter` 鍵

高對比度模式的特點：
- 更高的文字對比度
- 更清晰的按鈕邊界
- 更明顯的焦點指示器
- 自適應的顏色方案

## 螢幕閱讀器支援

所有互動元素都包含適當的 ARIA 標籤，以支援螢幕閱讀器：

### 頁面結構
- 使用語義化 HTML 標籤（`header`、`main`、`footer` 等）
- 提供跳過導航連結
- 清晰的標題層級結構

### 互動元素
- 按鈕和連結包含描述性的 `aria-label`
- 表單元素包含關聯的標籤
- 動態內容更新時通知螢幕閱讀器

### 遊戲元素
- 遊戲狀態變化時提供語音反饋
- 分數和時間更新時通知螢幕閱讀器
- 遊戲控制按鈕包含清晰的標籤

## 視覺輔助

### 文字大小
- 所有文字使用相對單位（rem/em）
- 支援瀏覽器的文字大小調整
- 清晰的文字層級結構

### 顏色和對比度
- 符合 WCAG 2.1 AA 級標準的顏色對比度
- 不依賴顏色來傳達信息
- 提供高對比度模式

### 動畫和過渡
- 提供減少動畫的選項
- 避免閃爍內容
- 平滑的過渡效果

## 音頻輔助

### 音效控制
- 可以完全關閉音效
- 提供視覺反饋作為音效的替代
- 音效音量可以獨立控制

### 語音提示
- 遊戲開始和結束時提供語音提示
- 重要事件（如得分）提供語音反饋
- 可以調整語音提示的音量

## 響應式設計

應用程式支援各種設備和螢幕尺寸：
- 自適應佈局
- 觸控友好的界面
- 支援不同的輸入方式（滑鼠、鍵盤、觸控）

## 錯誤處理

- 清晰的錯誤訊息
- 提供錯誤恢復選項
- 防止意外操作

## 最佳實踐建議

### 開發者
1. 使用語義化 HTML
2. 確保所有互動元素可通過鍵盤訪問
3. 提供適當的 ARIA 標籤
4. 測試螢幕閱讀器兼容性
5. 確保顏色對比度符合標準

### 使用者
1. 使用鍵盤快捷鍵提高效率
2. 根據需要調整文字大小
3. 在需要時啟用高對比度模式
4. 使用螢幕閱讀器功能
5. 提供反饋以幫助改進可訪問性

## 回饋和支援

如果您發現任何可訪問性問題或有改進建議，請：
1. 提交問題報告
2. 聯繫支援團隊
3. 提供詳細的問題描述和重現步驟
