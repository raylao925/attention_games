## 開始使用

### 系統需求
- 支援的瀏覽器：Chrome、Firefox、Safari、Edge 最新版本
- 建議螢幕解析度：1920x1080 或更高
- 需要啟用 JavaScript
- 需要網路連接

### 註冊和登入
1. 點擊右上角的「註冊」按鈕
2. 填寫必要的個人資料
3. 設置用戶名和密碼
4. 完成註冊後即可登入

### 個人資料設置
1. 登入後點擊右上角的個人頭像
2. 選擇「個人資料」選項
3. 可以更新以下資訊：
   - 個人頭像
   - 用戶名稱
   - 電子郵件
   - 密碼
   - 通知設置

## 遊戲介紹

### 專注力遊戲
- **目標**：訓練持續專注能力
- **玩法**：
  1. 觀察螢幕上的目標
  2. 在目標變色時點擊
  3. 保持專注直到時間結束
- **計分方式**：根據反應速度和準確度計算

### 記憶力遊戲
- **目標**：提升短期記憶能力
- **玩法**：
  1. 記住出現的圖案順序
  2. 按照順序重現圖案
  3. 難度會隨等級提升
- **計分方式**：根據記憶長度和準確度計算

### 反應力遊戲
- **目標**：訓練快速反應能力
- **玩法**：
  1. 等待目標出現
  2. 快速點擊目標
  3. 避免點擊干擾物
- **計分方式**：根據反應時間和準確度計算

### 靈活性遊戲
- **目標**：提升思維靈活性
- **玩法**：
  1. 解決不同類型的謎題
  2. 在限定時間內完成任務
  3. 適應不斷變化的規則
- **計分方式**：根據完成速度和準確度計算

## 常見問題

### 技術問題
1. **遊戲無法啟動**
   - 檢查網路連接
   - 清除瀏覽器緩存
   - 更新瀏覽器版本

2. **畫面卡頓**
   - 關閉其他應用程式
   - 降低遊戲畫質
   - 檢查系統資源

3. **無法保存進度**
   - 檢查登入狀態
   - 確認網路連接
   - 清除瀏覽器緩存

### 使用問題
1. **如何重置密碼**
   - 點擊登入頁面的「忘記密碼」
   - 輸入註冊郵箱
   - 按照郵件指示操作

2. **如何更改個人資料**
   - 進入個人資料頁面
   - 點擊編輯按鈕
   - 保存更改

3. **如何查看歷史記錄**
   - 進入個人中心
   - 選擇「歷史記錄」
   - 查看詳細數據

## 故障排除

### 常見錯誤
1. **錯誤代碼 404**
   - 檢查網址是否正確
   - 重新整理頁面
   - 清除瀏覽器緩存

2. **錯誤代碼 500**
   - 等待幾分鐘後重試
   - 檢查網路連接
   - 聯繫技術支援

3. **登入失敗**
   - 確認用戶名和密碼
   - 檢查大小寫
   - 重置密碼
